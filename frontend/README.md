# ViewerAtlas Frontend

The ViewerAtlas frontend is a React, TypeScript, and Vite portfolio interface for
exploring the aggregate community graph produced by the Python pipeline.

## Data Modes

- **Demo mode:** when `VITE_DATA_URL` is unset or unavailable, the app uses a
  bundled demonstration dataset and displays a visible demo-data banner.
- **Aggregate mode:** production builds fetch the same-origin
  `/data/frontend-data.json` export generated by the pipeline.

Remote data is shape-validated and size-limited before rendering. Raw chatter
usernames and VOD message content are not part of the public frontend payload.

## Development

```bash
npm ci
npm run typecheck
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

The build includes a restrictive script policy, same-origin data loading, route
code splitting, and no public source maps by default. Edge/CDN security headers
should still be verified at deployment time.

## Deployment

`deploy.sh` builds the app and uploads `dist/` to a private S3 bucket intended to
sit behind CloudFront Origin Access Control. Set `S3_BUCKET` and optionally
`DISTRIBUTION_ID` before running it.

The expected production data URL is configured in `.env.production`:

```text
VITE_DATA_URL=/data/frontend-data.json
```
