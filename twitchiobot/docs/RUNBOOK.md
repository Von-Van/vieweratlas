# ViewerAtlas Runbook

The operational runbook for the current EventSub collector is
**[Daily Operations](DAILY_OPERATIONS.md)**.

The former continuous Twitch IRC collector, `TWITCH_OAUTH_TOKEN` workflow,
discovery service, SQS worker fleet, and VOD task are retired and must remain
disabled. Do not use an older copy of this runbook to restart them.

For deployment or controlled rollout, use **[DEPLOYMENT.md](DEPLOYMENT.md)**.
For the release acceptance list, use
**[deployment-checklist.md](deployment-checklist.md)**.
